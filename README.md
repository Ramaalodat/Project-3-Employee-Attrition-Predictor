#  Employee Attrition Predictor

هذا المشروع عبارة عن أداة ذكاء اصطناعي تستخدم خوارزميات **تعلم الآلة (Machine Learning)** لتصنيف الموظفين وتوقع ما إذا كان الموظف معرضاً لترك العمل (Attrition) أم لا، بناءً على بيانات وظيفية محددة.

## نظرة عامة
تم تطوير هذا المشروع كجزء من متطلبات مشروع الذكاء الاصطناعي (Project 3)، حيث تم الانتقال من مرحلة معالجة البيانات إلى تدريب نموذج تصنيف (Classification Model) لتقديم رؤى (Insights) تدعم اتخاذ القرار في الموارد البشرية.

## التقنيات المستخدمة
* **Python**: اللغة الأساسية للمشروع.
* **Streamlit**: لبناء واجهة المستخدم التفاعلية (UI).
* **Scikit-learn**: لتدريب نموذج `Random Forest Classifier`.
* **Pandas**: لمعالجة وتحليل بيانات IBM HR Analytics.
* **Pickle**: لحفظ واسترجاع النموذج المدرب.

## طريقة التشغيل
1. **تثبيت المكتبات المطلوبة:**

```bash
pip install -r requirements.txt
```

2. **تدريب النموذج (في حال لم يتم ذلك):**
```bash
python train_model.py
```

3. **تشغيل التطبيق:**
```bash
streamlit run app.py
```

## هيكلية المشروع

* `app.py`: الواجهة الأمامية (Frontend) التي تربط المستخدم بالنموذج.
* `train_model.py`: كود تدريب النموذج ومعالجة البيانات.
* `attrition_model.pkl`: النموذج المدرب (الذكاء الاصطناعي).
* `employee_data.csv`: مجموعة البيانات المستخدمة (IBM Dataset).

## آلية عمل النموذج

يعتمد النموذج على خوارزمية **Random Forest**، حيث يقوم بتحليل 7 متغيرات أساسية للموظف (مثل الراتب، الرضا الوظيفي، وساعات العمل الإضافية) ليقوم بتصنيف الموظف إلى:

* ✅ **Retained (مستقر)**: احتمالية بقاء الموظف عالية.
* ⚠️ **High Risk (معرض للاستقالة)**: احتمالية ترك الموظف للعمل مرتفعة.
